Sequencing rationale: deterministic UI first (P1) because it's the lowest-risk, highest-visibility win and 80% built. Tool wrappers/perf (P2) next because they're self-contained and benchmarkable. Integrations (P3) carry the most wiring risk, so they come after the rendering foundation is stable. Eval/sandbox (P4) is last because it depends on the integrated tool set being final enough to evaluate, and it's the highest-cost phase.
