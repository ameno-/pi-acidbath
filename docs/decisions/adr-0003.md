# ADR-0003: Agent core is registry, runner, and envelope only

## Status
Accepted

*Tracked in Beads:* [acidbath-9ih.3](bd-acidbath-9ih.3)
*Linear:* [MIGHT-499](https://linear.app/acids/issue/MIGHT-499/acidbath-harness-core-agent-and-subagent-substrate)
*Date:* 2026-09-23
*Author:* Ameno

## Context
The user asked for OMP's agent/sub-agent *core*, not its delegation heuristics, workflows, or automatic fan-out. Pi already ships `createAgentSession` and a reference `subagent` example with chain/parallel modes.

## Decision
Implement profiles, discovery, bounded isolated `createAgentSession` runs, cancellation, a concurrency ceiling, streaming updates, and a structured `ResultEnvelope`. Expose an explicit `subagent` tool plus `/agents list|run`. Default max concurrency is 4. Nested child fan-out is off unless a profile sets it. Project-local profiles require TUI confirmation. Do not port OMP Task-tool policy, workflowz, or auto-orchestration.

## Alternatives Considered
- Slash-command-only runner with no tool: rejected; the requested substrate must be invocable by the model.
- Copy Pi's chain/parallel example wholesale: rejected; parallel is allowed only when explicitly requested, and chain/workflow policy stays out.

## Consequences
* Testable core without a TTY for registry/envelope logic.
* Workers still need the Pi SDK at the execution boundary.
* No silent fleet spawning.
